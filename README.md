# README

Cette solution est une application de test servant à tester des candidats pour un poste de développeur .NET.

Le code n'est donc pas parfait et peut contenir des bugs ou des imperfections intentionnelles.

### LibraryManagement 
C'est une API REST simple pour gérer une bibliothèque de livres et les emprunts des clients.

### GetAllBooks
Cette méthode permet de récupérer tous les livres disponibles dans la bibliothèque.

### AddBook
Cette méthode permet d'ajouter un livre à la bibliothèque.
